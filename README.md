# Bangla Web Fonts
**Bangla Web Fonts** is a free CDN providing fast and easy-to-use Bangla fonts for web projects. It allows embedding Bangla fonts into websites without local hosting.

🌐 Website: [banglawebfonts.pages.dev](https://banglawebfonts.pages.dev)

## Features  
- **Optimized for PageSpeed** – Fonts use modern formats like WOFF2 for faster load times.  
- **Supports Multiple Styles** – Includes Regular, Bold, and more font styles.  
- **Hosted on Cloudflare** – Ensures reliable and fast font delivery.  
- **Minified CSS** – For better performance, each font comes with a `.min.css` minified version.
- **Fonts Preloading** – Adding the preload link prevents FOUT and improves page loading speed.

## Technologies Used  
- **Astro**
- **Tailwind CSS**
- **Cloudflare**
- **GitHub**
